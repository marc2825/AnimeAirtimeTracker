# 実装方針

## 方針
まずは外部データ取得を後回しにし、ダミーデータでUI・データモデル・集計の骨組みを完成させる。
その後、しょぼいカレンダーの公式非HTML出力を前提に取得レイヤーを追加する。

## 開発順
1. Next.js + TypeScript + Prisma + PostgreSQL の初期構成
2. DBスキーマ初版作成
3. ダミーデータ投入
4. 検索一覧ページ実装
5. 作品詳細ページ実装
6. 放送枠詳細ページ実装
7. 統計ダッシュボード実装
8. フィルタとURL同期
9. テスト・README整備
10. 取得レイヤー設計
11. 実データ取り込み

## MVP完了条件
- ダミーデータで主要画面が動く
- 検索条件がURLに反映される
- 放送枠が独立エンティティとして扱われている
- ヒートマップと表形式集計が表示できる
